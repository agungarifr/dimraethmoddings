4 · Formula reference

Combat power
Physical CP = STR + 0.5·(AGI + ADV) Magic CP = INT + 0.5·(CHA + ADV)

Race/class passives override some coefficients:

Human Magician → ADV magic = 0.75 Human Brawler → ADV physical= 0.75 Minotaur Magician → STR magic = 0.50 Elf Magician → AGI magic = 1.00
Starting attributes & per-point cost
start[attr] = raceBonus[attr] + classBonus[attr] base[attr] = round( 0.5 · (raceBaseCost[attr] + classBaseCost[attr]) ) // ≤0 becomes 200 attrCost(p) = base · (1 + (p−1)/3)^1.1 pointCost(p, L) = attrCost(p) + 100·L

Points are always bought cheapest-first, so the cheapest available attribute is purchased next.

XP, level & caps
xpForLevel(L) = roundHalfEven( 100·L^1.5 + 150 ) XP for level 25 = Σ xpForLevel(1..24) = 122 409 Attribute cap = 99 · Level cap = 25
